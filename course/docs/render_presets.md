# 视频输出规格预设


> 本文记录本地输出基准。具体平台如果另有上传限制，应在发布前从高清母版另行转换，不反向降低本地母版质量。

## 一、画幅预设

| 内容线 | 比例 | 分辨率 | 帧率 | 用途 |
|---|---:|---:|---:|---|
| 课程讲解 | 3:4 | 1080×1440 | 30fps | 当前课程正式画幅 |
| 横屏衍生版 | 16:9 | 1920×1080 | 30fps | 只有明确需要时另做适配 |

## 二、课程审片版

审片版用于检查内容、字幕、配音、画面、动效和场景顺序：

```text
pipeline/output/course/epNN_<slug>/vK/course_epNN_<slug>_vK.mp4
```

它必须保持 1080×1440、30fps 和 48kHz 音频，但重点是快速、稳定地完成审阅。用户未确认具体 `vK` 前，不生成发布母版。

## 三、课程高清发布版

用户确认审片版本后，从相同版本的 HTML、WAV、timings 或高质量分幕源重新输出：

```text
pipeline/output/course/epNN_<slug>/vK/course_epNN_<slug>_vK_publish.mp4
```

推荐参数：

| 项目 | 发布母版基准 |
|---|---|
| 分辨率 | 1080×1440 |
| 帧率 | 30fps |
| 视频编码 | H.264；当前生产机使用 h264_nvenc，libx264 仅作明确批准后的备用 |
| Profile | Main 或 High，以制作索引 `video_profiles` 为准 |
| 像素格式 | yuv420p |
| 质量控制 | CRF 15～16（数值越低质量越高） |
| 编码预设 | slow |
| 音频 | AAC、48kHz、单声道、192kbps |
| 网络播放 | `+faststart` |

参考编码形式：

```bash
ffmpeg -i <高质量视频源> -i <48kHz正式整轨音频> \
  -map 0:v:0 -map 1:a:0 \
  -c:v libx264 -preset slow -crf 16 -profile:v high -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 48000 -ac 1 \
  -movflags +faststart -shortest \
  pipeline/output/course/epNN_<slug>/vK/course_epNN_<slug>_vK_publish.mp4
```

命令只表示 CPU 备用编码基准，不能在当前生产机静默替代 NVENC。实际输入应为该版本的高质量源。不得把低码率审片 MP4 简单提高目标码率后当作高清母版，因为已经丢失的细节无法恢复。

## 四、字幕与音频

- 字幕由正式 timings 驱动，音频 segment 与字幕行宽相互独立。
- 字幕清晰度应在发布版抽帧中检查，尤其关注小字号、细线和高对比边缘。
- 正式整轨 WAV 使用 48kHz、单声道 PCM；最终视频使用 48kHz AAC。
- 响度调整如果需要，应先测量再决定，不能把未经核对的统一响度参数写死到每一期。

## 五、独立封面

```text
格式：PNG
比例：3:4
尺寸：1080×1440
路径：course/episodes/NN-<slug>/cover.png
```

封面在四幕配音试听确认后与视频风格同轮交付并分别选择；审片通过后复核并复用。正式 `cover.png` 既作为发布时单独使用的图片文件，也作为第一幕最高定时图片层覆盖视频前 0.5 秒；底层动画和音频照常运行，因此不增加总时长或移动章节边界。必须从已包含封面层的同版源文件生成高清发布版，禁止在成片完成后追加封面并再次编码整部视频。

## 六、发布版验收

- `ffprobe` 核对分辨率、帧率、codec、profile、像素格式、音频采样率和声道；
- 全片 FFmpeg 解码返回 0；
- 检查高细节场景、渐变、网格、纹理、字幕边缘和运动画面；
- 核对发布版与用户确认的审片版内容一致；唯一允许增加的是用户确认的前 0.5 秒封面层；
- 核对封面时间窗内两帧与正式 `cover.png` 的 SSIM 达到制作索引门槛，并确认下一帧已经进入正文；
- 核对审片版与发布版解码音频 MD5 一致；
- 将真实发布版路径写入本期 `制作索引.json`，不存在时保持 `null`。
