# Vibe讲解稿创作与审查

进入[SOP写稿阶段](sop.md#1-先写观看主线和稿件)时先读本文；完成正文后转入[语义预览与字幕初切](captions_timing.md)。

## 创作与取材

本路线的目的，是用具体锚点、鲜明反差和有起伏的观看过程吸引观众，让人直观理解一个概念并产生共鸣。写作、选材和审稿都围绕这个目的；不以学术严谨、逐句论证或事实背景交代完整为创作目标。不能为了使每句话解释周全，反复铺垫、补充前提、重述结论，牺牲整篇的简洁、层次和吸引力。

先从资料和生活观察中挑出有代入感的处境、有意思的事件、鲜明的反差或可想象的意象，确定观看入口与主要发现，再组织成完整稿。已有观看主线简记开场的期待、展开怎样带来变化、结尾留下什么感受或认识即可。开场按[前三秒的观看理由](motion_design.md#前三秒的观看理由)先让观众接触具体处境或变化，后文接住这份期待，不用无关片头消耗开头。写稿时同步考虑哪些意思由可见事件、关系和结果表达，哪些需要文字点明，不先把正文写成独立讲完所有内容的配音稿再逐句配图；此时不要求完成分镜或动画。内容需要解释时，优先让具体动作、对象关系和结果承载解释；首次主题登场按[点题时间](motion_design.md#首次点题时间)留出位置，不机械先讲完定义再开始故事。

主线统一不等于例子统一。同一个人物或物件可以贯穿全片，只要经历、关系或观看范围继续发展；也可以换故事、研究或视角，共同推动对同一个问题的认识。推进可以是新事件、新理解、反差或情绪变化，必要铺垫、留白和回响也有作用。按内容组织铺垫、揭示、回落和再次推进，让观众的期待与感受发生变化；不把固定的高潮数量或曲线套到每期。具体人物、物件、数字或选择应成为能记住的锚点，每次接续带来新的发现或感受。换场景却仍反复解释同一结论时，应压缩或重组选材；不能因为某个例子容易解释、措辞稳妥，就让它占据后半片而失去推进。

语言要直接、具体、有画面和节奏。依靠上下文和画面建立含义，不要求每句话单独拿出来也解释完整。已交代的背景、角色和关系不反复说明；用具体动词推动事件，避免把一个动作展开成对动作的解释。允许比喻、拟人、夸张和有感染力的概括，不逐字考证修辞，也不为保险逐句补“可能”“未必”。

实验、研究、历史和生活材料只取观看主线需要的部分。可以只选一个选择、一组对照、一个动作或结果，允许压缩、概括和省略；不必复述完整实验，也不必解释材料的前因后果和全部条件。以观众能直观理解当前现象为准，不为补齐资料增加计算、背景和重复说明。完整出处及研究细节留在资料备注，不反向要求正文逐项补回。

具体数字用于形成比较、反差和记忆点。有依据的精确数值应保留；已说明是估计值时，不因追求措辞保险而自动改成“约”“超过”“不到”，削弱锚点。

素材核对与出处整理在资料层完成，不把严谨性检查变成逐句扩写正文的理由。不编造来源、研究数字或引语；发现核心意思讲反或所用材料不能支持当前表达时，用最短的措辞或画面调整解决。缺少完整背景、未覆盖所有情形、修辞无法逐字证明，均不要求补写或返工。

结尾从前文形成的意象、期待或矛盾中收束，可以留下新的看法、情绪或问题，也可以给出观众此时需要的办法。建议和直接提醒本身不等于说教；看它是否回应前文，而非突然站出来教育观众。不强制总结、安慰、励志或回到原场景，也不靠末句金句补救整篇缺少推进。

## 正文衔接与参考写法

用户提供或项目已有可用的参考纯旁白时，先完整阅读，理解它为什么让人停下、继续看并留下感受：选了什么材料，怎样安排发现，语言怎样形成画面，节奏怎样变化，结尾怎样获得前文支撑。学习整篇的创作选择，再用于本期；不只摘一句结尾或检查相邻连接词。参考不是固定结构，不把它的年份排列、实验数量、建议段或句式变成每期要求；引用其中事实时仍核对来源。没有参考也可直接创作，不新增外部查阅依赖。

转场可以承接疑问、建立期待、形成反差或唤起前文。“回到”“更离谱的是”“有意思的是”和必要编号都结合后文判断，兑现了期待就有作用；只报段落位置或空喊惊人而没有内容时再删改。重复也可以形成铺垫、强调和回响；重点是再次出现时有没有新的含义或感受，不按词语或重复次数判退。

文字密度由内容与画面共同决定。有的段落靠文字连续揭示，有的让动作展开并保留无字幕时间；不从某条参考推导全片统一字数或读速，不让文字复述画面已经清楚表达的每个细节。画面要解释的名称和正文覆盖仍按后续字幕与标注规则落实。

## 切分前的主线审查

完整初稿必须从第一幕连读到末幕，先判断整篇是否值得继续看：锚点是否鲜明，期待怎样被建立和兑现，反差是否逐步展开，情绪有没有起伏。再检查跨段、跨幕的重复：是否反复定义概念、解释同一种心理或把同一个结论换例子再讲。按[共同事实核验与单次润色](../common/script_content_review.md)执行一次润色时，沿用本节的取材范围，优先删减冗余、增强直接表达和观看推进；不能为追求真实性或严谨性，把一句话或整段解释得越来越长。改后连读相关接点，核对锚点、反差和节奏是否保留，不运行逐句学术审查、专家评分或多轮完整复审。

整篇啰嗦重复时，先删除、合并或重排重复段落，重新组织发现与情绪的推进；不能只缩短两句话、把长句拆短或增加过渡语就算修好。开场没有观看理由、展开持续重述同一意思，或结尾与前文脱节，都须修选材与组织后再切分。必要铺垫、停留和产生新含义的回响可以保留；措辞稳妥、资料完整和技术检查通过不能替代观看体验。后续画面按[结尾收束](motion_design.md#结尾收束)兑现正文建立的联系。

在已有`content_review`或审查记录中简记整体结论、实际发现的问题和处理结果，问题定位到具体句段；没有问题时简记结论即可。不逐段撰写“通过证明”，不另列情绪评分、参考分析表或新增审批。修辞不因无法逐字证明而判退，事实核验与修改保留必要来源依据。正文可读、观看主线成立且实质问题处理后，进入下面的切分与既有内容确认。

具体改稿先给用户确认，再改文件。讲解稿、切分预览和实际字幕须覆盖相同原文；原文标点保留到时间表，仅在最终显示时去掉，不能因此删句、改词或让道具标签取代完整文字。完整覆盖不等于整句必须同屏；完整问句优先保留语义，长句按[主字幕长度与分屏](motion_design.md#主字幕长度与分屏)处理，不因短句偏好硬拆。
