# Vibe固定配乐与混音

用于[SOP最终高清发布版配乐阶段](sop.md#4-固定背景音乐与混音)；全片画面确认后，再检查固定音乐文件并执行混音。局部小样、风格预览、分幕及整片画面审看均不加BGM；high质量与高清分辨率不代表已经进入配乐阶段。

动作声对应具体可见动作，切镜头不自动加沙沙声。先选音色，再检查音量、落点和密度。音乐、人声与动作声分别处理；先完成无人声版本，可选人声在成片后再讨论。需要精确踩音乐时提前确定素材和片段，后加音乐不声称已经按音乐重拍制作。

## 固定设置

Vibe系列固定使用《千年之后》氛围版试听音乐，项目内的固定本地路径为`.local/music/千年之后_氛围版_试听.mp3`。仅最终高清发布版本添加背景音乐，增益固定为`0.25`（25%），动作声增益保持`1`（100%）；这是用户已确认的系列设置，后续每期直接沿用，不重复选曲或询问比例。用户明确要求更换音乐或调整比例时，才处理对应变更。

首次配置将这份音乐放入上述位置；该目录已被Git忽略，音乐不随仓库提交。文件缺失或损坏时明确报告并补齐同一素材，不静默换曲。音乐是背景配乐，不生成旁白人声，也不触发声音克隆。

## 循环准备

最终高清发布版本的音乐从正片0秒开始，随视频结束。先用`ffprobe`读取无BGM底片的实际时长：音乐够长时直接使用固定原文件；不够长时，从头循环同一首到覆盖底片全长，生成本期的循环音轨，不换曲、不留无配乐的尾段。例如在仓库根目录执行，替换底片、期次、版本及实测秒数：

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 "底片.mp4"
ffmpeg -hide_banner -y -stream_loop -1 \
  -i ".local/music/千年之后_氛围版_试听.mp3" \
  -t "底片实测时长秒数" -map 0:a:0 -vn \
  -c:a pcm_s16le -ar 48000 -ac 2 \
  "course/episodes/03-topic-slug/bgm-loop-vK.wav"
```

循环只是重复原音乐，不自动做淡入淡出、交叉淡化或归一化。准备后复核音轨时长、循环接点和全轨解码；底片变长后重新核对，不能沿用较短的旧循环文件。保留固定原音乐及已确认版本，循环产物按本期版本另存。

## 索引与试听

在制作索引保留已确认的系列默认设置，记录曲目和比例不代表前期预览需要配乐；`bgm.file`在原音乐够长时指向固定文件，生成循环音轨后改填本期真实的循环文件路径。以下是正式默认值，不是待试听的候选比例：

```json
"bgm": {
  "file": ".local/music/千年之后_氛围版_试听.mp3",
  "source_gain": 1,
  "gain": 0.25,
  "approval": {
    "confirmed": true,
    "statement": "每次都是固定用这个。这个就是固定的背景音乐，就是不断重复，如果说他的背景音乐不够的话音量比例就是背景音乐25%。"
  }
}
```

已有系列确认可以沿用，不要求每期重新试听批准配乐；完整最终视频仍须按原审片节点确认。进入最终高清发布版配乐阶段后，只有用户要求试听或调整时，才生成分轨试听页：

```bash
npm run vibe:preview-music -- course/episodes/03-topic-slug/制作索引.json
```

试听页引用未混音乐的`review_base_output`，避免双重叠加；暂停和拖动时音乐同步。先准备够长的原音乐或循环音轨，再打开试听。页面上的滑杆或上次浏览器保存值不自动改变正式索引；用户明确要求的新比例才更新对应设置。所有增益均为线性比例，不自动归一化、压低原声或加淡入淡出。

## 混音与版本

```bash
npm run vibe:mix -- course/episodes/03-topic-slug/制作索引.json
```

全片画面确认后才执行本命令，不对前期预览或分幕小样执行混音。命令复制视频编码数据，另存最终高清配乐版并检查解码、声道、起止、时长和削波，保留底片与原音乐。先核验临时候选，通过后才替换输出；失败不覆盖已有配乐版。混音版更新`review_output`，需要审看这份完整最终视频；默认配乐未完成时，不将无BGM底片视为完整最终视频。

完整review始终写当前版本的无BGM底片，不把配乐路径当作画面输出。重建画面或改变混音后，旧发布验收状态失效；未变化的混音文件保留已有确认。已确认内容需要修改时另存新版本，复用未改动的媒体，再执行受影响阶段。
