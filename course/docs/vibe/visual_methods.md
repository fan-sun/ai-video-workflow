# Vibe画面组织与动效方法

用于[SOP画面编排](sop.md#2-先编排连续画面再落实字幕与时间)，帮助把已确认内容变成可实现的连续过程。先决定事件、空间或关系怎样发展，再用动效让变化清楚、有力度。四层要求仍由[动态画面规范](motion_design.md)维护，实际审看按[画面验收](visual_review.md)执行。

本项目提供[20种完整风格素材库](../../../examples/vibe-styles/README.md)，包含可播放场景、绘制源码和时间轴接入工具。先确定下面的表达任务，再查看适合的完整示例，直接复用其空间、材质与动效实现，按本期对象和接续调整；保留有效的细节，不先重写成简化图形。03、06、09、02、17、20为优先接入项，其余按题材选择并先验证实际片段。选择没有固定数量、顺序或构图，不仅替换标题便当作本期成片。

[基础动效工具](../../../examples/vibe-motion/README.md)继续提供路径推进、形态重组等底层状态计算，需要自定义动作时按需使用。完整场景与基础工具各有用途，不能把几项状态计算函数当作已具备原例完整美术与表现力。

## 怎样用于本期

1. **按相邻任务选方法。** 找出本段要让观众发现的变化，再从下表选适用方法或另行设计。外观与组织分别决定，不先锁定整幕人物站位、卡片区或容器，再往里塞所有内容。只处理正文已有任务，不为套方法擅加实验、建议或改动已确认讲稿。
2. **先形成本期画面编排。** 在逐屏定时和写动画代码前，按[画面编排文件](#本期画面编排文件)先统筹全片，再展开当前幕的具体过程；参考选择、对象关系与动作设计都落在同一份文件中。
3. **先验证关键连续段。** 使用实际整幕源码实现最需要验证的相邻任务，检查主体过程、空间联系与动作力度是否同时成立；成立后再扩展。不另做一段与整幕无关的漂亮片头来替代过程验证。
4. **按本期结果复查。** 对照计划中的状态与实际画面，记录已兑现项和具体差距，再连看整幕与接点。方法选择没有固定数量、顺序或组合，不要求每幕用遍本表，不新增审批或表单。

## 本期画面编排文件

每期维护一份当前有效的 `course/episodes/NN-slug/画面编排.md`，生成后在制作索引顶层 `visual_plan` 登记相对仓库根目录的真实路径。它是本期实现与复查的编排依据；通用规则仍在本目录维护，不整段复制进每期文件。文件标题后列各幕的简短进度，采用 `[ ] 待处理` / `[x] 已完成` 并注明编排、制作或验收的实际阶段，不能以“编排已写”代替“视频已通过”。

**先统筹全片，再逐幕展开。** 文件注明对应的正式稿、语义预览及当前制作版本，开头简记观看入口、主要发现或反差、结尾回报，以及各幕起止状态和幕间接续。随后只把当前要制作的幕展开到可执行程度，其余幕保留提纲；不要求开工前写完每一幕细节，不增加用户审批或独立设计评审稿。

每段以一次有含义的事件推进为单位，用简短段落或表格写清以下内容；不按每句字幕固定分镜，不规定段数、秒数或视觉模板：

- **对应内容与观看任务：** 用语义预览中的幕号、条目位置或原文片段定位，说明观众要看见、发现或感受到什么；不能只写抽象结论。
- **连续过程：** 开始时谁在哪里、什么状态，什么触发变化，中间怎样发生，可见结果是什么，结果怎样交给下一段。进入、交接、分离、比较等关键动作必须有能辨认的过程，不能只写“人物移动”“走入区域”或“结果出现”。空间边界、对象接触和前后关系按本段含义明确，不强制写实。
- **画面与表现：** 主要对象的识别特征、场景关系、光影与材质方向；观众先看哪里，镜头为什么改变范围，动作怎样起动、响应和落定，哪里快速揭示、哪里需要观察。特效说明作用于哪个对象、增强哪次变化；采用素材库时记录具体源文件及保留的有效绘制或运动，不只列风格编号。
- **文字与节奏配合：** 哪个动作需要字幕补充，哪段由动画独立推进，必要标签怎样贴近主体。写相对先后与快慢、阅读和停留理由；完整字幕与精确秒数只在画面时间表维护，文件引用对应时间表及其已有字幕ID，不另抄一套字幕时间轴。
- **实际验收点：** 写出能在连续视频里观察到的关键过程、结果和接点，以及准备先验证哪段。验收点不能只是“丝滑”“有动效”或“符合参考”。未准备的素材、未展开的动作和未核实的效果如实标注。

**进入实现前，由助手连读当前幕及前后接点。** 如果无法据此说清主体从何处、经什么变化、到达何种状态，或关键解释仍只有文字标签，就先补编排；缺少当前幕完整过程时不直接写动画。前三秒观看理由、首次点题、[知识点展示后的阅读停留](motion_design.md#知识点展示后的阅读停留)和结尾依据现有规范落实到具体事件；编排指出哪个展示需要辨认及如何接续，精确时刻继续只在时间表维护，不另复制规则表。

改变点题、揭示或段落长度时，重新检查受影响的整段事件与字幕关系。无字幕段须有编排中的任务，不能仅在原字幕之间插入空档并顺延后文，就认定已完成节奏重排。原有事件与节奏确实仍成立的部分可以保留，但须连看接点验证。

**只维护一份当前编排。** 恢复已有期次时，从动态参考记录、时间表的 beats 等位置提取仍有效的设计，并补齐过程；旧文件保留历史事实，后续不并行维护另一套当前方案。时间表如保留 beats，只作动作定位或编排条目的简记，不再复制完整设计。方案改变先更新本文件，再同步时间表和代码；动作无法实现时重设计或明确记录待处理，不悄悄简化后把原验收点改成已通过。已确认版本需要保留时按既有版本规则归档，制作索引始终指向当前有效编排。

每幕完成后按[实际画面验收](visual_review.md)对照正文、编排和实际视频检查，并在已有验收记录中保存具体时段与差距；本文件只更新状态和验收记录链接，不再复制完整报告。编排完整、素材已使用和技术检查通过，都不能代替连续画面验证。

## 画面怎样随任务发展

下表是组织方法，不是固定分镜。主体可以是人物、物件、路径、数量或抽象关系；是否换景、运镜以及快慢由当前任务决定。

| 当前表达任务 | 可执行的状态接续 | 观看时应能辨认的变化 |
|---|---|---|
| 同一空间中，条件改变后续去向 | 先建立行动路径 → 新条件实际作用于路径或对象 → 对象绕行、分流、受阻或抵达新区域 → 新去向成为下一段起点 | 原因与后果在同一过程中发生；环境可以保留，不能只在底图轮流亮起标记 |
| 同一对象承接不同判断 | 保留对象的可识别特征 → 从行动中的物件转为比较或判断依据 → 注意转向它影响的另一对象或后续结果 | 对象身份有联系，表达职责和视觉中心随任务变化；不必让所有内容永远待在原容器里 |
| 从局部发现整体，或进入内部机制 | 建立局部与周围的真实位置联系 → 展开范围或进入内部 → 新范围中有此前看不到的内容与相互作用 → 用新关系解释原局部 | 推近有新过程可看，拉远揭示局部所处的位置；不是整张插图统一放大缩小 |
| 双方接触同一事件，获得的信息却不同 | 保留共同事件 → 展示信息怎样被发送、接收、遗漏或补全 → 两方据此产生不同反应 → 将差异带到下一步判断 | 用信息的连续性、范围、顺序或缺失体现差别，名称贴近对应对象；不能只有“甲这样想／乙那样想”两块文字 |
| 预期与实际结果产生反差 | 先建立预期或比较基准 → 让观众看见总量与实际变化 → 保留符合条件的部分或形成不同去向 → 必要时把同一结果整理成更容易比较的形式 | 数量、比例、范围或结果本身产生反差，变换表现形式后仍是同一批数据；不先亮出完整答案再依次高亮，也不夸大数据 |
| 展示一种操作或判断如何起作用 | 先看见原有困境 → 实际改变一个条件或做一次操作 → 物件、关系或反馈发生变化 → 结果回应原问题 | 办法有演示过程与反馈，而非只出现一张建议卡；正文没有方法任务时不强行增加 |
| 回到开场或旧对象完成收束 | 接回观众认得的关键状态 → 用已发生的证据、选择或关系变化重新理解它 → 留下新的判断、感受或去向 | 旧画面返回时有新的观看含义，不从头重播相同动作；结果成立后可以安静落定 |

小动作也可以承担核心过程。例如，同一信号在一处保持完整，在另一处只留下零散片段；如果这种变化正好解释双方的信息差，固定镜头就有作用。若两边只是无关地晃动，差异仍全靠文字解释，则没有兑现这个任务。重点是动作在表达什么，不是幅度越大越好。

某次比较、筛选可以用卡片完成。若后续任务转向困住、改变判断或行动结果，却仍只是同一布局继续添卡片、换高亮，就应重新决定观看主体或关系。反过来，不能因为使用了卡片或固定镜头便直接判失败。

## 动效怎样服务这些过程

先有上面的事件与关系，再选择下表的实现方法。外观可采用线条、平面图形、纸感、体积感或其他统一语言；材质本身不决定整幕怎样发展。

| 要呈现的过程 | 实现时要做出的中间变化 | 使用边界 |
|---|---|---|
| 接触、受力与人物响应 | 触发物先动，接触或连接到位，受影响物再响应；按含义安排蓄力、速度变化、跟随和落定 | 起动时间、方向及响应幅度要能看清；不让所有物体同速平移，也不要求每次接触都弹跳 |
| 路径生长、分流与抵达 | 对象位置随同一条路径推进；经过节点后再改变后续路线，环境细节按前中后景接续 | 路线变化须有原因或信息任务，不能用光点循环绕圈充当新的发展 |
| 局部进入与整体展开 | 在移动前建立嵌套位置；主体、边界、遮挡与远近层使用一致的空间关系，移动中显露新内容 | 镜头只负责看见过程，不替代对象事件；必要文字按阅读任务处理缩放与遮挡 |
| 聚合、分离与形态重组 | 给参与变化的部分保留对应关系，沿可追踪路径分开或汇合；中途有连续形态，落定形成新状态 | 可用点、线或完整物件；不把两张图交叉淡化当成同一对象变形，也不让所有概念都变成粒子换词 |
| 条件筛选与数量揭示 | 同一批对象按条件分别保留、退出或转向；数量、标签和后续图形由同一结果驱动 | 各组去向和差异应明显；图形形态可以变，数值含义不能变，必要解释不能只留在远处图例 |
| 随动作显现内部、状态或材质 | 让揭示边界沿对象推进，经过的位置发生相应改变；对象身份与标注仍能对应 | 只有揭示新的结构、状态或重点时才用；普通扫光只能增强质感，不能冒充机制解释 |
| 焦点交接与关键揭示 | 前一状态触发收拢、展开、重组或明暗重心变化；次要对象退后，关键对象获得清楚的尺度和对比，再把结果交给下一段 | 按本期含义选择表现，不固定粒子、闪白或标题入场组合；不清空上下文插通用片头 |
| 空间质感与连续环境 | 明确光源、前中后景及遮挡；对象经过时，阴影、视差或反射作相应变化 | 背景变化服务主体所在的空间，不能凭光斑、网格、纹理和轻微漂移判定内容在推进 |

## 接入当前制作方式

在本期实际源码中，把同一事件涉及的对象、数量、形态及标注放在可同步的状态计算中；状态计算遵守[共同确定性契约](../common/visual_contract.md#确定性渲染规则)。共享空间的主体、遮挡和路径使用一致的坐标关系，主字幕保留稳定阅读区；必要场景文字按阅读任务跟随主体或在新位置接住，不跟着世界缩小到无法阅读。

继续遵守[实现与渲染入口](visual_review.md#实现与渲染入口)，复用本项目已有绘制与动画能力，素材按[共同素材接入](../common/visual_contract.md#素材与输入签名)登记。本地素材库的[接入步骤](../../../examples/vibe-motion/README.md#接入本期制作)说明资产路径及如何使用已有时间轴；在本期实际源码中验证，不仅看素材预览。本期实现放在本期期目录及画面目录；没有验证过的效果不标记为可用能力，复杂材质、阴影或模糊先在实际小样检查画质与耗时。

字幕、必要标注、点题、背景及声音使用本项目现行规范，不从组织方法推导新的字号、时长、配乐或固定构图。实现中需要改变时间时同步已有时间表和预览，不拉伸装饰动画凑字幕时间。

## 对照验证与返工

在现有验收记录中，对照计划与本期小样写清：哪个对象经历了什么变化，留下什么结果，下一任务如何接住；画面力度和阅读是否支持该过程。证据链接指向本期实际片段及具体时段，方法名称或技术检查不能替代结果。

- 若任务已经改变，编排仍只能通过换标签和轮流高亮表达，退回编排重选主体、范围或关系。
- 若编排有清楚过程，但实际被做成弹出、淡入、整体缩放或无关循环，修实现并重看完整过程。
- 若过程成立但动作难辨、力度失配、解释缺失或文字移动中被遮挡，修表现与标注；不靠延长静止尾段放行。

先按[连续小样检查](visual_review.md#先验证连续小样)验证关键相邻任务，再复查整幕及接点。抽帧可以核对状态，正常速度和手机观看尺度才能检查节奏与可读性；观察范围如实记录，不把状态图检查写成完整动态审看。
