# Vibe动态画面设计与检查

这份规则用于[Vibe路线](sop.md)。先确定观众为什么想继续看，再设计事情怎样发生；动作、运镜和特效共同服务内容。

## 全片先有观看主线

写清入口、情绪锚点、贯穿矛盾、主要揭示和结尾回扣。每段应接住前面的期待，带来新的发现、关系或情绪。知识名称可以较早出现，揭晓名称后继续解释机制和后果；避免拖到很后面才点题。

允许必要停留、重复和静止，但它们须服务阅读、情绪或理解。不机械规定每句动作数、固定重拍时间或爆点数量。先粗排总时长，再逐幕验证，避免第一幕几十秒后才发现全片过长。

## 先写动作，再安排镜头

每段至少写清：对应原文，观众要看懂什么，开始状态，动作过程，结果差异，空间和光源，镜头的信息任务，字幕阅读时间，具体动作声，与下一段的接点。

开始、中途和落定必须有可辨认的不同状态。投币要有进入、接触和落下；选择要有不同去向或数量；承诺落空要先建立双方共同计划，再表现一方退出及另一人的回应。只画一个人开门，无法自动表达两个人的矛盾。

关闭运镜后，主体仍应发生动作或关系变化；镜头可以揭示尺度、空间与联系，但静态图放大、缩小、横移不自动成为连续动画。对照不能只换颜色、文字和数字。信息逐步出现，避免先摆出完整答案再依次高亮。

人物可以简化，保持自然形象和基本动作逻辑。行走方向、身体与手臂转向、手与物体接触应一致；夸张速度可以服务感受，断开的手指、倒着走或物件无故悬空需要修正。

## 背景也参与表达

先确定场所、前中后景、光源和视觉重点。统一配色、材质和光影方法，具体环境随生活、研究或抽象段改变，不全片套同一张背景。

要求明显改善时，用认可样片确定变化幅度，正常播放尺寸下应看见环境轮廓、光照分区和空间深度。必要时直接替换墙、地、窗景；不要只在被旧墙遮住的底层继续加暗线。背景不能代替主体动作，也不能抢走字幕。

近景、主体和远景随镜头保持空间关系，视差有前后层次。镜头每次移动都说明它在揭示什么，不为炫技增加无意义摇晃。

## 连续段和幕间衔接

上一段的动作结果成为下一段的起点，避免每句都重新摆一套场景。整幕制作前看前一幕收尾，检查对象状态、镜头位置、明暗、字幕及声音怎样接上；合并前再检查所有实际交界。

全幅环境末帧应持续铺满画面再淡出，不跟随前景缩成一块矩形。抽样必须包括过渡中途，不能只看前后两帧。

“这些事”“这样过”“这个问题”等指代要有对应的可见情境。结尾先建立观众需要思考的具体关系，再回扣前面的主题；外围礼物、日历和粒子只能辅助中心。

## 字幕和声音保持主次

原文完整显示，去标点不等于删句或改稿。主字幕留稳定阅读区，不随镜头旋转缩放。完整语义和能读完优先，不强迫每条七字或每句强调。

只对必要的具体词着色，每幕通常不超过三个；普通句子可以完全使用基础色。逐处选择，不把某词的所有出现位置自动高亮。强调跟字幕进出，换句和倒退定位后应正确清除。

高信息量动作、密集小字和主字幕不同时争夺注意力。重点主体持续可见，次要经历和细节可以掠过、降低亮度或退后，形成动感而不淹没含义。

动作音效有可见对象和落点；不为每次切场、字幕出现或运镜加音效。先比较音色，再确定密度和音量，整轨播放检查是否吵或太弱。背景音乐单独试听，确认后混音。

## 实际检查与返工

先渲染最容易暴露问题的连续小样，覆盖动作开始、过程、结果和相邻接点。使用实际整幕源码，不另做一套无法接入的漂亮静态样稿。

1. 不读字幕，能否认出主体在做什么、发生了什么变化。
2. 正常速度播放，节奏、动作幅度、关注点与接点是否清楚；无法完整播放时如实记录观察方式。
3. 比较实际MP4的开始、中途、落定帧，差异不能只靠读标签才能辨认。
4. 检查字幕覆盖、阅读、重点、遮挡，以及音效对象和密度。
5. 再结合布局、首次可见、反向定位、完整解码、尾帧与接点检查。像素一直在变不证明叙事或审美达标。

同一问题反复出现时，回到整段动作设计，不继续加缩放、摆件和小幅漂移。用户指出局部问题时保留认可部分；只修改受影响段，完成局部验证后重建该幕，其他有效幕复用。一轮设计自查后进入动画验证，有具体问题再修，不每轮新建外部评审稿。
