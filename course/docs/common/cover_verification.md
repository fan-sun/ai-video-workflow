# 共用封面文件与实际图片检查

进入所属路线封面阶段时调用；候选数量、视觉风格、生成工具、尺寸和嵌入行为由路线规定。

## 文件与证据

候选保存在本期 cover-options/，保留提示词或可修改源码，临时生成文件先复制进项目。交付可点击实际图片，登记实际采用工具、真实像素及选择结果；模型名称只在可核实时记录。封面选择与视频风格分别记录，未生成的图不能当作已获认可。

代码图片等待字体和素材加载后通过真实浏览器出图，不能只交 HTML 或根据源码坐标宣称视觉通过。AI 图片检查实际像素和内容，不伪造 HTML 验收报告。不可把插值放大说成更高密度的原生渲染。

## 图片检查与返工

在原尺寸与手机缩略图分别检查焦点、主题识别、字形、错字、裁切、边缘、遮挡、光影和空间；辅助信息不抢主信息。构图、风格及内容要求继续按路线评判，工具成功和无越界不能代替实际审美检查。失败修正后重新检查受影响图片；共享字体、样式或素材改变时检查全部受影响候选。

build/common/check_course_cover.mjs 只对 1080×1440 代码画布执行实际 PNG、字框、布局遮挡检查。其他尺寸或 AI 图片按实际图片核验，不能声称已通过该 HTML 检查器。

多候选 HTML 展示可使用[静态候选展示指南](browser_visual_review.md)，但正式图片渲染不可豁免。确认事实及版本处理按[共同执行规则](execution.md)，交付登记按[共同发布协议](release_delivery.md)。

## 1080×1440 代码封面检查器

```bash
node --env-file-if-exists=.env build/common/check_course_cover.mjs <候选HTML路径...> --out <本期质检目录>
```

工具等待字体并真实渲染每个候选，输出同名 PNG 和 JSON，检查页面与图片尺寸、文字越界、语义元素重叠、实体背景遮挡及标题安全区。失败修正后重跑受影响候选；未变且报告对应当前源码及素材的结果可复用，共享依赖改变时重跑所有受影响候选。

含文字的实体背景卡片标记 data-audit-box，以检查外框及内部文字。刻意装饰重叠使用 data-overlap-ok，不豁免越界；只对允许超出画布的局部装饰用 data-overflow-ok。标题、正文、流程节点及语义卡片不得用这些豁免，合法祖先嵌套无需豁免。

浏览器、字体或截图失败必须停止，不退回只看 HTML 字符串或坐标后宣称通过。采用代码封面对比页时展示已通过检查的真实 PNG，同时提供独立源码链接；仅缩放 iframe 不能代替候选截图。实际图仍须按前文检查审美，不能凭报告通过放行。
