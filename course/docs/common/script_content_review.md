# 共用事实核验与单次润色

在所属路线的初稿审查节点读取本文。知识完整度、叙事推进、修辞和内容确认顺序由路线决定；共同规则不另加审批。

## 核验与来源

实际采用的研究、数据、引语和核心事实保留可追溯来源，不虚构或更改结果，不把推测写成已证实事实。来源采集按[选题规则](topic_selection.md)。具体哪些内容进入正文、哪些限定放在资料备注，由所属路线的内容要求判断。

## 单次润色规则

AI 必须完整读取项目本地 .agents/skills/copy-editing/SKILL.md，再对全部正式文字做一次统一润色。本地副本来源于 coreyhaines31/marketingskills@copy-editing，日常生产不临时下载上游；只有用户明确要求升级时更新。文件缺失或不可读时报告并停在写稿阶段，不静默下载或替换技能。

改善清晰度、语气、口语节奏、具体程度和“为什么值得关心”；保留事实、来源及因果，不凭空添加数据、案例、经历或观点。不执行销售 CTA、营销转化或零风险改写；只运行一次，不串联 write、humanizer-cn 或其他写作技能，不为常规生产生成 A/B/C 稿或额外测试文件。

各路线在润色前说明其专属保留项，润色后完成所属路线的复核与切分。后续返工按实际问题修正，不自动再跑一轮润色。记录只写实际检查、问题及结论，不以工具完成代替内容通过；确认范围按[共同执行规则](execution.md)。
