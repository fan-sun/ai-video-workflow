# 共用事实核验与单次润色

在所属路线的初稿审查节点读取本文。内容取舍、叙事推进、修辞和内容确认顺序由路线决定；共同规则不另加审批。

## 核验与来源

实际采用的研究、数据、引语和核心事实保留可追溯来源，不虚构或更改结果，不把推测写成已证实事实。来源采集按[选题规则](topic_selection.md)。具体哪些内容进入正文、哪些限定放在资料备注，由所属路线的内容要求判断。

核验以本期实际表达为范围。允许概括、省略非核心信息，并按已确认受众默认日常常识、约定的前置知识和前文背景；不因没有覆盖全部背景、例外或实现方式而要求补写。只有省略会使当前核心意思讲错、证据无法支持当前结论，或影响关键操作判断时，才补最短的必要条件。来源与研究细节通常留在资料备注，不为预防假想误解逐句追加限定或免责声明。

## 单次润色规则

AI 必须完整读取项目本地 .agents/skills/copy-editing/SKILL.md，采用其中的快速检查（Quick-Pass Editing Checks）对全部正式文字做一次轻量润色。本地副本来源于 coreyhaines31/marketingskills@copy-editing，日常生产不临时下载上游；只有用户明确要求升级时更新。文件缺失或不可读时报告并停在写稿阶段，不静默下载或替换技能。

改善清晰度、语气和口语节奏，优先删减冗余；允许删除不影响本期理解的注释和旁枝，不以补齐信息为目标。保留事实含义和因果，不凭空添加数据、案例、经历或观点。不逐句强求证明、数字、例子或收益，不执行七轮回查、专家评分、销售 CTA、营销转化或零风险改写；只运行一次，不串联 write、humanizer-cn 或其他写作技能，不为常规生产生成 A/B/C 稿或额外测试文件。

各路线在润色前说明其专属保留项，润色后完成所属路线的复核与切分。后续返工只修实际问题及受影响句段，不自动再跑一轮润色或完整审查。记录只写实际检查、问题及结论，不以工具完成代替内容通过；确认范围按[共同执行规则](execution.md)。
