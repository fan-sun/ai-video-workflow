# 共用 HTML 合成、素材与确定性契约

用于两条路线的正式画面源与构建版。画幅、正式时间来源、字幕切分及品牌规则由所属路线定义；本文只维护共同实现约束。

## 合成与字幕接入

1. body 下直接存在独立合成根，不用 template 包裹；根具有唯一 data-composition-id="main"、data-start="0"、明确画幅和 data-duration，根及祖先宽高可解析。
2. data-duration 与 const DUR 等于所属路线正式时间表的本幕时长；不能从临时画面反写正式内容。
3. 同步创建单个暂停 GSAP 主时间轴，注册到 window.__timelines["main"]，注册键与合成 ID 一致；先创建时间轴，再注册字幕动画。
4. 正式源只保留一个 /*__SUBS__*/ 注入点；构建版注入后不得残留占位符。字幕生成方式、单位和高亮字段由路线定义；显示层不得私自增删、合并或改写正式文字。
5. 同一时刻正向播放、直接 seek、倒退定位得到一致状态。所有关键动画能由时间轴定位，不能依赖播放历史。

## 素材与输入签名

外置素材在 acts[].visual_assets 登记相对仓库路径，构建入口按文件名复制到 assets/ 并纳入输入签名。文件名须互不冲突，HTML 使用 assets/<文件名> 引用；字体和素材需实际存在并在渲染前加载完成。新增或修改素材时检查复制和缓存依赖，不能只改源文件却沿用旧缓存。

build/ 只放跨期工具，本期源码和脚本位置按[登记文档](topic_selection.md#标准路径与目录初始化)。

## 确定性渲染规则

- 随机布局使用固定种子的 PRNG，不用未设种子的 Math.random()。
- 不用 Date.now()、performance.now() 或真实时钟驱动画面。
- 不通过 setTimeout、Promise、异步回调或事件监听构建正式时间轴；字体和素材加载准备与时间轴播放分开。
- 不用无限 repeat: -1；循环有限并限定在本幕内。
- 关键动画使用 opacity 和 transform，不用 display 或 visibility 切换替代关键过程。
- 不让多个时间轴同时修改同一元素同一属性。会缩放、回弹的对象按峰值预留空间；场景退出后不残留遮挡下一段的高层。
- 布局声明按[渲染前门禁](render_verification.md#渲染前门禁)，不能用整幕豁免绕过检查。

## 初始可见状态

- 延后入场的信息在首帧前通过 CSS opacity: 0 或等效确定性初态隐藏，之后以明确起止值入场。布局占位或暗色但可辨的内容不等于隐藏。
- fromTo 的 immediateRender: false 只推迟应用 tween，不能保证默认可见的元素预先隐藏。
- 父场景出现不能提前暴露稍后才展示的子文字、数值、连线和结论；父子显隐共同检查。
- 场景开始、入场前、落定后及从片尾倒退的实际可见性，按[首次可见复核](visual_review.md#首次可见复核方法)执行；不能仅凭源码写了动画就判通过。

## 检查交接

实现前读取本期 visual_plan 及路线时间表；实现后执行[共用视觉检查](visual_review.md)与[渲染验收](render_verification.md)。对象和字幕的路线专属表达效果仍按所属路线验收，不由本契约替代。
