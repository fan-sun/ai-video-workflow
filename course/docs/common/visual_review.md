# 共用视觉检查方法与证据

两条路线在画面制作和成片复查阶段调用本文。它定义检查方法，不定义两条路线各自的叙事目标、字号、构图或节奏。路线验收应在本方法之上检查本期表达是否兑现。

## 检查方式与通过范围

先对照独立于代码形成的 visual_plan，检查开始、中间、结果和相邻接点；再看实际 MP4。截图能核对状态，正常速度连续审看才能判断动作、节奏和语义；不能把自动播放结束、像素运动或静态抽帧写成完整审看。

记录真实视频版本、时段或帧路径、预期与实际、失败修正和复查结果。不能审看时如实写待核验。技术结果、助手视觉判断和用户认可分别保存；局部通过不等于整幕通过，整幕通过不等于整片获确认。

## 对象可识别性验收

- 对照 visual_plan 主体清单，查看稳定帧及动作片段。遮住名称仍能凭关键外形认出具体对象，不能以写名称的普通方框替代汽车、工作台或人物。
- 对象应足够大，部件和关系可辨，不能只是大文字卡角落的小图标。涉及放置、行驶、取出等动作时须实际参与动作，不能只有标签移动。
- 照片、插画、三维、SVG 或代码绘制按所属风格选择；抽象节点、消息、表格和界面可使用文字容器，不要求把每个抽象概念拟人成物件。
- 制作前在本期编排登记主体、识别特征、素材或绘制方式、参与动作；素材先准备并查看，外部素材保存来源及使用条件，代码绘制保存源文件和对象标识。未准备不能记已就绪。

失败须修改对象或场景并复验；像素运动、布局、首现及解码通过不能抵消。

## 阅读、动作与遮挡

理解动作必需的名称、数字、单位和解释应在同一关注区域与对应主体同步可读；按路线的字号和阅读规则检查。检查移动中途、交叉处、最小尺度及落定状态，不能只看两端静帧。字幕与主体不互相遮挡，层级、字体、对比及显示时段正确。

在正常播放和手机观看尺度检查实际 MP4；读不清、解释不同步、要跨屏找含义或必要标签被遮挡时，修正并重看完整路径。不能只靠暂停放大或延长静止尾段放行。

## 首次可见复核方法

- 以本期画面编排独立列出每个计划入场的信息元素或同时表达同一信息的元素组，记录目标、对应内容、计划首次可见时间；不能只从动画代码生成清单后自证通过。检查范围包括父容器内稍后才讲到的文字、数值、连线和结果标记。
- 渲染前在实际浏览器中检查：场景刚开始、首次可见时刻前一帧、入场完成后的稳定帧，以及先跳到片尾再倒退回入场前一帧。前两种状态不得暴露后续信息，入场后须正常可见；直接 seek 和顺序推进应一致。
- 既检查元素自身的初始显隐，也检查父容器和子元素共同形成的实际可见结果；不能让尚未显示的父场景掩盖子元素初态错误。CSS 中已经能读出的暗色内容算可见，不算隐藏。
- 渲染后从实际 MP4 抽取同样语义节点的动作前后帧，并查看对应连续片段，核对初始局部、中间新增和最终整体。分步出现不能造成空白讲解、已讲内容无故消失、标题孤立标点或文字压框。
- 逐幕把首次可见检查的时间点、预期/实际状态、失败修正及例外理由写回 `visual_plan` 的验收记录；采用程序化检查时，把 `first-reveal-report.json` 保存在该幕构建目录并登记路径。数量通过不能替代对计划时间是否符合内容的判断。

这项检查由 AI 在画面阶段执行，不增加用户确认步骤。`review/publish` 中实际构建分幕的路径在渲染前调用 `build/common/check_course_reveal.mjs`，检查 `data-reveal-at` 元素自身透明度的入场前、入场后和从实际片尾倒退状态，失败阻止渲染；长入场动画可用 `data-reveal-duration` 指定从入场到检查的秒数，默认 0.9 秒。依赖可由 `PUPPETEER_ROOT`、`CHROME_PATH` 指定，默认查找本机已安装的 HyperFrames 依赖与 Chrome。无标注时报告为 `not_applicable`，不能声称首现已通过；AI 仍须按本期画面编排核对标注覆盖、祖先遮挡、场景起点及内容语义，`npm run check` 本身仍不含此项。发现提前展示时，按 [初始可见状态契约](visual_contract.md#初始可见状态) 修正，再复核受影响画面。

主体停滞工具只能发现像素停滞；完整画面提前出现后持续移动，也可能通过。因此 `motion-report.json` 的 `passed` 不能代替首次可见及语义复核。交付时分别记录“首次可见检查”“主体停滞检测”“语义对位复核”和“用户审片”状态，不得将静态截图或像素运动检查写成全片动画体验已通过。


## 接点与完整成片

关键帧覆盖开头、场景中段、转场前后及中途、结尾前和实际末帧。时间点按本期实际边界选择，不机械照抄示例。

逐个检查整期时间表的实际幕间边界：幕序正确，无黑帧、花屏、重复帧、上一幕残留；音频无意外缺失、重叠或跳时；下一幕从正确状态开始。最终正常速度通看完整版本，检查字幕、遮挡、转场、音画对应及全片起伏。不能只看 HTML 末态替实际导出尾帧通过验收。

一个版本任一必查项失败或未核实，不登记整体通过；失败回到所属路线的设计或实现阶段处理。未变的有效部分可复用，已否定或未核实的旧段不能因本轮未修改而视作通过。
