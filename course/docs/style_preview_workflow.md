# 课程制作 · 固定视频风格选择流程


> 本文负责正式画面制作前的视频风格选择。视频风格从长期固定的 A/B/C 预设中直接选择。封面仍按 [封面流程](cover_workflow.md) 生成三张本期候选并独立选择；端到端顺序见 [SOP](sop.md)。

## 一、固定风格目录

固定预设目录长期保存在：

```text
course/docs/video_style_presets.html
course/docs/assets/video-style-presets/
├── A-archive-mechanical.png
├── B-technical-route.png
└── C-bright-modular.png
```

三个方向使用同一中性主题展示稳定画面，只用于识别视觉语言，不随期次重新生成：

| 方向 | 固定名称 | 视觉语言 | 典型运动 |
|---|---|---|---|
| A | 纸本机械 | 暖纸张、档案仪器、刻度、机械夹具 | 主题词翻转、扫描并锁定 |
| B | 技术路线 | 米白网格、深蓝路径、节点、坐标关系 | 路线逐段绘制并抵达主题 |
| C | 明亮模块 | 浅色点阵、彩色模块、聚焦圆环、工具卡 | 组件聚合并突出主题 |

对应开场母版位于 `templates/course-opening-3x4/a|b|c/index.html`。选择 A、B 或 C 同时确定“对应固定开头 + 对应风格正文”。固定开头必须从所选母版原样接入，不得重新设计一个配色或气质相似的替代版本；正式正文只继承该方向的背景基调、配色、字体气质、图形语言和运动节奏，仍须根据本期对象、关系和叙事顺序设计场景。

固定预设图或母版发生实质变化时，重新生成三张预设图并复核目录；普通期次不得修改共享预设来适配单期内容。需要新增第四种长期风格时，单独评估并更新目录、母版和本文，不在单期制作中临时扩充。

## 二、选择时机与用户门禁

四幕正式配音通过技术验收和用户试听确认、第四幕片尾处理及整期时间表完成后，进入本阶段：

1. AI 按 [封面流程](cover_workflow.md) 生成并验收本期 A/B/C 三张封面候选。
2. 同一轮交付固定视频风格目录和本期封面对比页。
3. 用户分别选择视频风格与封面，允许跨组，例如“视频 A，封面 B”。
4. 用户已在本期较早阶段明确选择且预设未变化时，直接复用，不重复询问。
5. 视频风格和封面均选定后，进入正式画面制作。

固定预设目录已经代表 A/B/C 的长期选择依据。浏览器只作为可选展示渠道，本地 HTML 和三张 PNG 可直接查看；展示失败不改变选择事实。

## 三、所选风格如何进入正式画面

视频风格控制全片的背景材质、主色、字体层级、边界、图形语言和运动节奏，不固定每幕版式、卡片数量或主体位置。固定开头是所选风格唯一必须原样复用的完整画面结构；开头以后的正文与开头结构相互独立，只保持视觉风格一致。正式画面仍按旁白逐步构建，并遵守 [画面制作](visual_workflow.md) 与 [视觉系统](visual_system.md) 的对象、首次可见和语义对位规则。

正式第一幕直接以所选方向的共享母版为开场技术与视觉基础，再接入本期正式音频和 timings：

- 知识教学使用“今天要学习的是 XX”，按主题词实际朗读起点完成翻转、转正和定格；
- 开场只呈现第一句所需信息，不提前展示后续定义、例子或结论；开场 DOM、素材与动画必须来自制作索引记录的所选共享母版，不得另写近似版本；
- 开场与正文的衔接在第一幕源 HTML 内完成，不生成独立候选短片；
- 音画落点、布局、对象、完整渲染和解码随正式第一幕一起验收。

开场结束后，母版中的控制台、框架、状态栏、刻度尺、模块位置和场景结构必须退出，不得作为正文外壳常驻。正文场景必须根据本期内容设计可识别对象、关系和动作；“固定风格”只表示正文与开头属于同一视觉系统，不表示正文继续位于开场界面中。

## 四、制作索引

新一期在 `制作索引.json` 中按以下方式记录：

- `style_options`：三个固定预设 PNG 路径；
- `style_comparison`：`course/docs/video_style_presets.html`；
- `selected_style`：记录 A/B/C、固定名称、预设图、共享母版，以及配色、材质、构图和运动说明；
- `cover_candidates`、`cover_comparison` 和 `cover_selection`：继续按封面流程单独记录。

视频风格选择后，课程状态改为“画面制作中”。第一幕完成时，将实际正式源写入 `acts[0].visual_source`；不以独立开场 MP4 代替正式第一幕。

共享开场母版位于 templates/course-opening-3x4/；生成工具 build/create_course_openings.mjs 用于接入本期正式音频和主题词。
