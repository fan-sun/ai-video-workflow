# 课程制作 · 视频内章节进度条

本仓库从第一期起，review 与 publish 的四幕正文使用同一条视频内章节栏。本规则不改变平台发布文案中的【视频章节】格式。

## 标题与时间来源

- 四个标题只维护在本期 `制作索引.json` 的 `chapter_titles`，视频内章节栏与发布文案逐字共用。标题应是能独立表达该幕内容的几个词，优先不超过 7 个汉字，不设硬字数上限；不写完整句、内部幕号或“第一部分”之类空泛名称，也不保留首尾空白。
- 阶段 5 的 review 前将四个标题写入制作索引并定稿。标题内容超过单格可用宽度时，画面最多显示两行，末尾由浏览器以省略号截断；发布文案仍保留完整标题。不能为了凑进格子而改写发布时间或挪动章节边界。
- 四格宽度由 `整期时间表.json` 的四幕精确起止秒数占整期总时长的比例计算。播放进度从全片 0 秒连续前进，到第四幕结束才走完，不按幕平均分配，不在换幕时重置。发布文案的时间码仍按原规则四舍五入到整秒。
- 任一幕 timings、时间表或章节标题变化后，重建受影响分幕、整期审片版和同版本发布版，重新核对发布文案。不得手动在画面源和文案中各写一套标题或时间。

## 画面与开场

- 画布为 1080×1440。正文顶部章节栏高 100px；文字区最多两行，进度轨道位于其下方。底轨为浅灰，已播放部分为浅红。四格的分割线止于轨道上方，不留额外横线或悬空竖线。
- 章节标题初始为深蓝。红叶走过后，进度轨道上方对应的整片文字区逐步盖上浅灰滤镜，文字与底色一起变浅，表示这一段已经看过；当前章节可呈现左侧灰、右侧原色。进度轨道维持原有浅灰底和浅红已播放色，不受滤镜影响。
- 四个标题在各自的幕宽内都能单行显示时，标题区收为 60px、字号用 28px，进度轨道、红叶和已播放浅灰覆盖层同步调整位置；只要有一个标题需要两行，就沿用 80px、26px 的双行布局。章节栏整体仍占顶部 100px。
- A/B/C 正文的章节栏共用这一套米色、深蓝和浅红配色，不随所选正文风格切换。
- 红叶使用同一份模板素材，缩为 52×52px，其中心跟随已播放进度前沿，并完整显示在文字层与轨道之上。正文不得再出现另一枚固定红叶或重复的课程顶部标题。红叶可以覆盖章节文字，不为它改动各格的文字宽度。
- 独立封面前 0.5 秒和所选 A/B/C 固定开场原样播放，不显示章节栏。第一幕的章节栏在实际开场结束时出现；以正式开场源的 `id="opening"`、`data-duration`，或索引中的 `opening_overlay.duration_s + fade_s` 为准，不能写死全片秒数。开场本身的红叶不受正文规则影响。
- 正文主体从章节栏下方开始设计，不把旧开场状态栏、品牌标题或额外顶线叠在章节栏下面。章节栏占用顶部 100px，不缩小主体内容、字幕或画幅。

## 构建与验收

`build/common/course_video.mjs` 在临时构建版 `index.html` 中注入章节栏；四幕正式源 HTML 不复制章节组件。`--check-only`、`--range`、完整 review 和 publish 都走同一准备逻辑。构建前核对所需分幕的 `timings.total` 与整期时间表对应幕时长；第一幕开场之后才显现，后续幕从首帧显现，并从该幕的整期累计位置继续前进。构建内容签名包括标题、时间表和注入代码，缓存不能掩盖修改。

验收时至少检查：封面、开场末帧与正文首帧；四幕开始和结束前后；一个窄章节与一个长标题。核对标题和发布文案一致，格宽和时间比例一致，红叶与浅红进度前沿同步，幕间没有回跳；文字最多两行且可见部分无裁切，超长标题以省略号收尾，轨道下方无旧顶线或分割线残段，字幕及主要内容可读。浏览器布局检查会把有意的两行省略误判为文字裁切，因此只对章节标题元素跳过该项审计，必须用实际抽帧复核；不得扩大到整栏或正文。抽帧通过后仍须观看连续片段，确认运动和切换。
