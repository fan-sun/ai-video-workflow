# 教学发布配套要求

发布包格式、总结长度、章节时间、真实登记及公开发布授权只按[共同发布交付](../common/release_delivery.md)维护。本文件补充教学专属内容。

- 标签必须有三个独立标签 #AI、#AI基础、#深度讲解，可再加主题标签；长标签和带前后缀的标签不能替代对应独立标签。
- 概念讲解的视频总结直接回答“它是什么、为什么重要、有什么必要边界”，不用讲解结构代替知识总结。
- 发布章节与[视频内章节栏](video_chapter_progress.md)共用 chapter_titles；画面省略不改变文案全称。
- 正式封面及平台上传封面按[教学封面流程](cover_workflow.md)。媒体从 standard 审片到 high 发布、首帧封面、音轨和片尾检查按[教学渲染验收](render_verification.md)。
