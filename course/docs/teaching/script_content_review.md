# 教学讲解稿内容审查

初稿完成后读取本文。先完成教学内容审查，再按[共同单次润色](../common/script_content_review.md#单次润色规则)处理；通过后进入本文件规定的顺读复核和切分。

## 一、审查目标

审查确认三件事：本期核心意思是否讲对、目标观众能否听懂、讲述是否自然连贯。按已确认的选题范围判断，不以原始资料覆盖率或零遗漏为目标。

短视频允许取舍。原始资料中的标题、分类、背景、次要结论和例外不自动成为必讲项；可以默认目标受众具备日常常识和约定的前置知识，也可以依赖前文语境，不要求每句话单独拿出来都解释完整。

这一步不负责逐句润色或决定配音断句。完成一轮内容检查并解决实质问题后，按共同规则做一次轻量 `copy-editing`，通读复核后进入切分；不为凑齐检查项反复扩写或重审。

## 二、输入与结论

审查时读取用户提供的原始资料、课程台账中已确认的受众与选题范围、当前完整讲解稿，以及实际采用的一手来源。

结论按是否存在实质问题判断：

- **通过**：核心事实准确、本期核心问题讲清、主线可懂，可以进入单次润色；
- **需修改**：指出具体错误或理解障碍，局部修正后复核受影响段落；只有问题涉及全篇时才扩大修改范围。

非核心信息缺失、表达偏好或可有可无的补充不阻断流程，也不另列待补清单。

## 三、内容取舍与默认前提

从原始资料和已确认选题中识别回答本期核心问题所需的内容：

- **需要保留**：支撑核心理解的定义、关键关系或机制，以及用户明确指定的重点；
- **可以省略**：不影响本期理解的分类分支、背景、次要数字、重复案例、术语辨析和非关键限制；
- **可以默认**：目标受众的日常常识、约定的前置知识，以及前文已经交代或上下文可以自然推知的信息。

不强制建立逐项资料覆盖表，正常省略无需逐条说明理由。不得擅自删除用户明确指定的重点；影响已确认选题范围的重要取舍，在既有内容确认时简要说明。

## 四、核心理解检查

围绕本期核心问题，判断目标观众能否用自己的话说明核心概念或结论，并理解支撑它的关键过程或关系。只有缺少某项信息会让这里听不懂或理解错误时，才要求补充。

分类、相近概念对比、操作建议和局限均按本期需要选择，不要求每期凑齐这些维度。只解释当前理解必需且受众尚不熟悉的术语，不为理论上可能出现的误解主动开新话题。

## 五、整篇连贯性检查

隐藏画面说明，按播放顺序通读全部旁白，结合前文检查：

- 是否突然换了话题，观众难以理解它与前文的关系；
- 是否为了塞入资料、注释或概念辨析而打断当前讲解；
- 是否反复解释同一件事，却没有带来新的理解；
- 结尾是否能从前文自然得出。

发现实际断裂时，优先删去偏题内容或调整顺序，不用空泛过渡句硬接。幕间可以用问题，也可以自然陈述，不要求每幕末句和下一幕首句机械构成问答，或脱离上下文也能独立成立。

编号、简短回顾和必要强调按作用判断，不凭某个词语或一次重复判退；能帮助理解就可以保留。

## 六、新增内容与边界检查

实际使用的研究、数据、引语和核心事实按[共同事实核验](../common/script_content_review.md#核验与来源)处理。新增信息应服务本期核心问题；生活比喻和普通解释不要求逐句另找证明，但不能改变技术含义。

只有删去限定会把当前意思讲错、把证据支持的范围扩大，或影响关键操作判断时，才在旁白里保留最短的必要条件。完整出处、非关键研究细节和其他实现方式留在资料备注；没有在正文提出的结论，不额外补反驳或免责，不因每个案例都有特定背景就例行强调不可泛化。

没有把握的非核心内容可以直接删去；若涉及核心结论或用户指定重点，则核实后再用，不以增加模糊限定代替核实。

## 七、需要阻断并修改的问题

- 核心事实或机制讲错、前后矛盾，或使用了无法支持当前结论的研究、数据和引语；
- 缺少必要信息，导致目标观众无法理解本期核心问题，或形成关键的错误判断；
- 明显跳题、重复或硬接，已经妨碍整篇理解；
- 遗漏用户明确指定的重点，或偏离已确认的选题范围。

没有讲全分类、没有解释常识、没有逐个澄清相近术语、没有交代所有例外，本身都不构成阻断理由。

## 八、教学润色保留项与后续复核

运行共同润色时保留核心意思、影响结论的必要条件、用户指定重点、四幕结构及已确认往期推荐；允许删减和重排非核心内容。概念讲解保留“今天要学习的是 XX”及概念名称规则，第一幕 S0 直接点题，不在概念名之前增加故事或悬念。

教学路线的润色结果回写同一份 `course/scripts/NN-<slug>.md`，不另存一份“润色稿”。润色后通读一次，确认改动没有改变核心事实、丢失必要条件或制造跳跃，并检查 `旁白：...` 可解析性。发现问题只修改并复核受影响句段及接点；不重复建立覆盖表或多轮完整复审。完成后立即进入切分预演，不在讲解稿阶段单独停下来请求用户确认。已确认稿件的返工按教学 SOP 保留原版本。

## 九、通过后的流程

按第八节完成单次润色与复核后，立即生成整期旁白切分预览。同一条交付消息提供：

- Markdown 讲解稿路径；
- 整期旁白切分预览路径；
- 简短审查结论，仅说明本期核心内容、实际发现的问题及处理结果；没有实质问题时说明结论即可，不逐项写通过证明；
- 明确请用户同时确认“内容”和“切分”。

用户确认前，不固定四幕正式 JSON，不生成正式配音。
