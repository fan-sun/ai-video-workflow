# 教学发布后的重建输入

重建链路：

```text
同版分幕画面源 + 引用素材/字体 + 正式音轨 + 字幕时间信息 + 章节/封面配置
  → 生成构建副本与字幕
  → 渲染各幕无声视频
  → 合入各幕声音
  → 拼接、加入封面及发布音频
  → 最终发布视频
```

共同源码、素材、原件及候选判断按[共同重建清单](../common/published_cleanup.md#共同重建输入与待核对候选)。教学额外保留正式分幕 JSON、各幕 WAV 与 timings、配音处理记录、章节和首帧封面配置。

原始逐句 WAV 可能包含被裁掉的声音，最终 WAV 经过裁切、变速、拼接后不能无损恢复原始音频；尚存的逐句原始 WAV 和裁切素材保持保留。只需从最终 WAV 重建整片不等于可恢复逐句编辑素材，不能将放弃原始素材称为删除可重建缓存。

**当前入口的额外依赖：** `build/common/course_video.mjs` 的教学 publish 步骤从 `review_output` 审片 MP4 复制音频。因此现有命令链还依赖这份审片 MP4，不能只因为它叫“审片版”就删除。若要删除，必须先验证可从保留的音轨重建所需审片输入，或提供不依赖该 MP4 的发布音频输入。不能把“各幕 WAV 都在”直接当作现有 publish 命令已能原样恢复的证明。

共同删除条件、原件与确认记录保留、独立重建验证及工具暂停状态只在[共同清理规范](../common/published_cleanup.md)维护。
