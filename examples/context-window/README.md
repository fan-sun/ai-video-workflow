# 上下文窗口 · 技术链路示例

这个短示例用于验证制作流程：自带教学稿、四幕图形与固定封面，配音由你提供的参考声音生成。示例使用模型官方说明中的一般概念；真实课程仍须按 SOP 调研和用户确认。

先按 [安装说明](../../course/docs/common/setup.md) 填写 `.env`，然后从仓库根目录依次运行：

```bash
npm run example -- prepare
npm run example -- audio
npm run example -- video
npm run example -- package
```

- `prepare` 创建隔离的示例工作区、正式脚本、整期切分预览和制作索引。
- `audio` 一次加载 VoxCPM 合成四幕，处理为 1.15 倍速整轨和 timings，追加第四幕一秒静音并生成时间表。
- `video` 根据真实 timings 构建图形，复用 A 开场，真实渲染封面及四幕，输出审片样例。
- `package` 生成同版章节文案、高清输出并执行发布包验收。

工作区在 `.local/context-window/`，成片路径由命令输出。这里使用独立的示例台账，不占用你的正式第 1 期；声音、模型和生成产物不提交到 Git。重复执行同一阶段会复用已验收产物，输入变更时明确停止，不能覆盖已确认素材。

示例固定选择 A，用于技术检查，不写用户确认、试听通过、审片通过或公开发布事实，也不上传到平台。正式课程继续执行 SOP 的确认门禁。
