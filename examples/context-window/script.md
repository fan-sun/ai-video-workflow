# 深度讲解 · 技术示例 · 上下文窗口

## 第一幕 · 一次请求的范围

### S1 · 点题
旁白：今天要学习的是上下文窗口。
画面点子：主题词旋转后定格，复用纸本机械固定开场。

### S2 · 定义
旁白：它限定了模型一次请求中能够处理的输入和输出范围。
画面点子：纸张进入有边界的工作台，展示当前请求。

## 第二幕 · 输入占用容量

### S3 · 工作台比喻
旁白：把当前请求想成一张工作台，资料就是桌上的纸张。
画面点子：先出现工作台，再逐张加入资料纸。

### S4 · 范围
旁白：问题、对话历史和参考资料，都可能占用这张桌子的空间。
画面点子：三类纸张依次进入工作台的容量边界。

## 第三幕 · 输出也要留空间

### S5 · 输出
旁白：模型的回答通常也需要空间，不能把容量全部塞满。
画面点子：输入资料旁逐步出现输出纸张，并保留空间。

### S6 · 边界
旁白：具体的输入和输出上限，要以所用模型的说明为准。
画面点子：用刻度显示总容量和单独输出限制。

## 第四幕 · 使用方法与边界

### S7 · 行动
旁白：使用时先留下任务必需的信息，再为回答预留空间。
画面点子：多余纸张移走，所需资料留在工作台上。

### S8 · 局限
旁白：窗口更大不等于理解更好，关键信息仍需要清楚组织。
画面点子：散乱资料整理成可读顺序，结尾保留一秒静音。
